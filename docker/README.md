# Docker + NGINX DevOps Project

A production-ready Docker project demonstrating how to containerize and serve a web application using Docker, Docker Compose, and NGINX.

---

## 📌 Project Overview

This project demonstrates:

- Docker Image Creation
- Docker Compose
- NGINX Reverse Proxy
- Multi-container Architecture
- Production-ready Deployment
- DevOps Best Practices

---

## 🛠 Tech Stack

- Docker
- Docker Compose
- NGINX
- HTML
- CSS
- JavaScript

## 📂 Project Structure

```
docker/

├── Dockerfile

└── screenshots/
```

---

## 🚀 Build Docker Image

```bash
docker build -t nginx-project .
```

---

## ▶ Run Container

```bash
docker run -d -p 80:80 nginx-project
```

---

## ▶ Using Docker Compose

```bash
docker-compose up -d
```
