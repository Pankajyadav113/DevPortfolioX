## 🚀 Getting Started

Clone Repository

```bash
git clone https://github.com/Pankajyadav113/DevPortfolioX.git
```

Go to project

```bash
cd DevPortfolioX/frontend
```

Install

```bash
npm install
```

Run

```bash
npm run dev
```
